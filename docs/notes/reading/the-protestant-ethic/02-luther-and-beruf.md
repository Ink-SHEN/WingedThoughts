# 二、路德的天职观

## 1. Beruf 这个词本身

韦伯的一个著名观察是：现代欧洲语言里表示"职业"的词，几乎都带有"神的召唤"这层底色。

- 德语 `Beruf`、荷兰语 `beroep`、英语 `calling`、法语 `vocation`；
- 而在天主教主导的语言里，对应的词（如 `profession`）只指世俗的行业。

`Beruf` 的现代义项，很大程度上是路德翻译圣经时定型的——最常被引的是《便西拉智训》与《哥林多前书》7:20 的译法：人应当"守住"神所赐给他的位分。

## 2. 路德做了什么

路德的贡献是**价值等级的倒转**：

| | 中世纪天主教的等级 | 路德宗的重估 |
| --- | --- | --- |
| 最高形态 | 修道院的出世禁欲（evangelical counsels） | 在世俗天职中履行义务 |
| 日常劳动 | 世俗的、次等的、难免沾染罪的 | 神所安排的、应当忠心去做的 |
| 得救途径 | 圣礼、告解、善功、最终靠教会中介 | 唯凭信心，日常劳动是信徒的本分 |

由此，"在世上好好干你的活"第一次获得了正面的宗教意义：职业不再是修行的障碍，而是修行本身。

## 3. 但路德还不是资本主义精神

韦伯在这里踩了刹车。路德的天职观有一个关键的限制：

- **顺从主义**：天职是神给你安排的位置，人应当安分守己，而不是设法改变处境、不断向上流动；
- **传统主义**：够用就好，强调适度与满足，不鼓励无限扩张；
- 路德本人对高利贷、对世俗营利持强烈的批判态度。

所以路德提供的是**地基**而非**动力**：他让世俗劳动变得神圣，却没有给出"不断增值、永不满足"的心理引擎。一个路德宗信徒可以在自己的铺子里安稳度日，但他没有理由把利润重新投进去、把生活压成一套纪律。

> [!NOTE] 为什么动力要从别处找
> 韦伯认为，需要一种比"顺从"更强的心理机制，才能把日常劳动变成系统性的、持续的、自我强制的行为。加尔文宗的预定论，恰好提供了这台引擎——这是下一篇的主题。
