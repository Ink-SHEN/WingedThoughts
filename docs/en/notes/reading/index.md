## How this section is organised

One book = one sub-section, with a fixed internal shape so new books are easy to add:

| Level | File | Purpose |
| --- | --- | --- |
| Book page | `<book>/index.md` | Bibliographic info + entry navigation; enough on its own |
| Entry | `<book>/NN-<topic>.md` | One theme per entry — readable alone, or in numeric order |

The numbering on the book page is the suggested reading order. Body text carries the argument; quotations are set off in blockquotes so they stay findable later.

To add a book: create a directory, write the content, register a sidebar group, push — see <a href="../website/NewNote">Adding a New Note</a>.
